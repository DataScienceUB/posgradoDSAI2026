# Postgraduate in Data Science & AI · Course resources

Universitat de Barcelona · Facultat de Matemàtiques i Informàtica. All material is in English.

This repository is where we leave **the resources of the course**: guides, notebooks, exercises and data. Everything is organized by session in the [`Sessions/`](Sessions/README.md) folder: one folder per session (`Session_NN`), each with its own `README.md` that explains what is in it and in what order to use it.

> [!WARNING]
> **Before Session 02, prepare your environment.**
> There are tasks to do **before the class** (accounts, installation and a check notebook). They are not part of the 2 hours of class, and the first minutes of Session 02 start from their result.
>
> 👉 **[Go to the preparation guide](Sessions/Session_02/pre_class/README.md)**

## How to use this repository
* Start from the `README.md` of the session you need.
* New sessions and resources are added as the course goes on, so check this repository before each session.
* Do not work directly inside your copy of this repository if you want to keep your own changes: the guide of Session 02 explains how to organize your folders.
