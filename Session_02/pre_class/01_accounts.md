# Part 1 · Accounts (the formal part)

[← Back to the guide](README.md) · Next: [2 · Installation](02_installation.md)

Nothing to install here, only accounts. **Do this first**, because some of it involves waiting for a verification.

## 1.1 GitHub account
**GitHub** is the website where repositories (project folders with their history) are stored, and where the course resources are.

1. Go to <https://github.com/signup> and create an account ([official guide](https://docs.github.com/en/get-started/start-your-journey/creating-an-account-on-github)). Skip this if you already have one.
2. Add your **university e-mail address** to the account if you can (*Settings → Emails*). It is needed for the student benefit below.

## 1.2 Free GitHub Copilot for students
Copilot is one of the AI assistants we will use. It is **free for verified students**.

1. Request student verification at <https://education.github.com/students>. GitHub accepts a university-issued e-mail and/or dated proof of enrolment.
2. When you are verified, activate **Copilot Student** in your *GitHub Education benefits* ([official instructions](https://docs.github.com/en/copilot/how-tos/manage-your-account/getting-free-access-to-copilot-pro-as-a-student-teacher-or-maintainer)).

> Verification can take **a few days**: start it early. If it is not ready for the class, do not worry: you can still follow the session.

## 1.3 Access to the course repository
The course repository is <https://github.com/DataScienceUB/posgradoDSAI2026>. Depending on how we configure it, you may need to be **invited** to see it. If GitHub says *"repository not found"*, check that you are signed in with the account the instructors gave access to.

## 1.4 Claude (later)
We will also use **Claude** inside VS Code. **We will give you the credentials later**, and we will set it up together. For now you only need to install the extension (Part 2). If you already have access to Claude and want to try it, go ahead, but it is not required.
