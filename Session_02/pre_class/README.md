# Session 02 · Prepare your computer (before the class)

This is the **preparation part** of Session 02. You do it **on your own, before the class**, at your own pace. You do not need any programming experience: every step is explained and every command can be copied as it is.

## What is this about?
During the course we will work in a **reproducible environment**: the same tools, the same versions, on every laptop. Preparing it before the class lets us spend the class time **working with data and AI assistants**, not installing software.

When you finish you will have:
* **Visual Studio Code** (the program we work in), **`uv`** (creates a clean Python environment for each project) and **Git** (keeps the history of your work).
* A **GitHub account**, and the **AI assistants** (GitHub Copilot and Claude Code) installed in VS Code.
* A project folder and a **notebook where every check shows ✅**. A screenshot of it is your ticket for the *traffic light* at the start of the class.

## The guide is split in four short parts

| # | Part | What you do | Time |
|---|---|---|---|
| 1 | [**Accounts**](01_accounts.md) | The formal part: create your GitHub account and request the free student benefit (**start this first**, it can take days) | 10 min + waiting |
| 2 | [**Installation**](02_installation.md) | Install VS Code, `uv`, Git, GitHub Desktop and the VS Code extensions | 20 min |
| 3 | [**Verification**](03_verification.md) | Create your project, run the check notebook and take the screenshot (**the required exercise**) | 15 min |
| 4 | [**Optional: your first repository**](04_git_exercise.md) | Create a repository and clone it, to check your GitHub credentials | 10 min |

Also useful: [Command cheat sheet](cheatsheet.md) · [Troubleshooting](troubleshooting.md) (with a Plan B if notebooks do not run in VS Code).

> **Why `uv`?** A *project* is a folder. `uv` records inside that folder which Python and which libraries it needs, so the project works the same on your laptop, on your classmate's laptop and next year. You do **not** install Python separately: `uv` does it for you. ([uv documentation](https://docs.astral.sh/uv/))

## Stuck? It is fine.
The first minutes of the class are exactly for this (the *traffic light*). If something stays red, take a screenshot of the message and bring it to the class.

*Screenshots were taken on macOS with VS Code in English. On Windows and Linux the windows look very similar; menus may be in a different place (for example *File → Open Folder…* instead of *File → Open…*).*
