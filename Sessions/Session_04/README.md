# Session 04 - MiniProject BiciBCN

Esta sesion se organiza como un mini-proyecto de 2 horas, en el que los estudiantes aplican lo aprendido en la sesión anterior a un conjunto de datos real: el registro de bicicletas públicas de Barcelona (Bicing). El objetivo es que los estudiantes puedan extraer, transformar y cargar los datos, y luego analizarlos y visualizarlos.

El enunciado, datos y directorio de trabajo se encuentran en el siguiente repositorio plantilla https://github.com/DataScienceUB/mp1-plantilla.

Debeis crear un nuevo repositorio a partir de esta plantilla, y trabajar en él. Para ello debeis usar el botón "Use this template" en la página del repositorio, y luego clonar el nuevo repositorio en vuestro ordenador usando VSC.
